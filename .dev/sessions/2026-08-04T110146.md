Recorded the Emotion-replacement decision in the roadmap: ShadCN on Base UI with `cva` for variant styling, made in another Overture project's research and adopted here.

- `.dev/roadmap.md`: "Replace Emotion with a less constrained styling solution" marked decided (ShadCN/Base UI/`cva`), with the Radix-to-Base-UI context verified against shadcn's own July 2026 changelog (Base UI is the new default; Radix is not deprecated). The two items it gates (theming engine extension, a11y audit) updated to reference the decision instead of an open question.

Catalogue-scoped server paths now accept a documentType in place of a catalogueId when it names exactly one catalogue, closing the gap the Components `catalogue` prop work exposed (a client that only knows a documentType previously had no server-side way to resolve it to the real catalogue).

- `apps/search-server/src/catalogues/findCatalogueByIdentifier.ts` (new): shared resolver: exact catalogueId match always wins; otherwise resolves an unambiguous documentType match; reports `ambiguous` (with every matching catalogueId) when a documentType is shared by more than one catalogue, rather than silently picking one.
- `apps/search-server/src/arrangerRoutes.ts`: multicatalogue branch now rewrites the leading path segment via the resolver before the per-catalogue mounts, preserving query strings; returns `409` with an `ambiguous_document_type` error body on collision. Single-catalogue mode is unaffected.
- `apps/search-server/src/introspection/index.ts`: `GET /introspection/:catalogueId` uses the same resolver; same `409` contract on collision.
- `docs/concepts.md`, `docs/reference/05-introspection.md`: document the resolution and ambiguity rules. Also fixed three pre-existing space-hyphen-space violations noticed in these files while editing them.
- `CHANGELOG.md`: entry under Server.
- Tests: `findCatalogueByIdentifier.test.ts` (new), `introspectionRoutes.test.ts` (new, first route-level coverage for `createIntrospectionRoutes`), plus new cases in `arrangerRoutes.test.ts`.
